# Archived Implementations

This directory contains historical `TASK.md` and `PLAN.md` files generated under the pre-Compound Engineering "Vibe Coding" prompt workflow (GitHub Copilot Chat prompts and Claude Code slash commands in `.github/prompts/`). Each subdirectory corresponds to a completed issue or feature.

These files are kept for institutional memory. The current contributor workflow uses Compound Engineering skills (`ce-plan`, `ce-work`, `ce-code-review`, `ce-commit-push-pr`) with plans living under `docs/plans/`.
